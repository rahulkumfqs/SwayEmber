# SwayEmber

SwayEmber optimizes web development workflows with high-performance, low-latency, live-reloading and auto-restarting capabilities through distributed node agent architecture.

With SwayEmber, you get a lightweight tool that stays out of your way.

**What you get**

- SwayEmber optimizes web development workflows
- with high-performance, low-latency, live-reloading and
- auto-restarting capabilities through distributed node

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/SwayEmber.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SwayEmber is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
